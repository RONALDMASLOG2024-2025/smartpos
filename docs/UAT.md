# SmartPOS UAT report

Date: October 5, 2026 (Asia/Manila). Local UAT uses fictional Manager Alex Reyes (`manager@example.test`), Cashier Sam Cruz (`cashier@example.test`), additional Cashier Taylor Santos and separately labelled sample sales. No real payments, Google accounts or cloud records were created by these tests.

## Verification scope

Final local checks: **27 automated business/database/HTTP-contract tests**, **4 browser UAT suites**, and **1 production safety test** passed. TypeScript, ESLint and the demo-disabled production build passed. `npm audit` reported zero vulnerabilities. The synthetic model artifact was regenerated and its SHA-256 remained identical (`fff4005ca398c2e5…`). There are 22 screenshot files.

- Business tests: money precision, permissions, immutable receipts, idempotency, insufficient stock/payment, stale prices/stock, failed persistence rollback, Cashier restrictions, account revocation, CSV validation/atomic import, formula-safe exports, image validation, deterministic synthetic and real-history model inference.
- PostgreSQL tests: execute the actual migration/RPCs/RLS in PGlite, using mocked Supabase `auth` and `storage` schemas. Include mid-sale failure injection, competing submitted checkouts, cross-store isolation, private image folders, restricted provisioning, legacy CSV migration and Cashier cost/history restrictions.
- Supabase HTTP contract tests: use the real JavaScript client against a mocked service to verify both roles can load 1,001 products beyond the service row cap, Cashier calls avoid protected cost/inventory endpoints, and checkout submits exact parameters and surfaces server errors.
- Browser UAT: actual UI journeys in Chromium at 1440×1000, tablet 768×1024 and mobile 390×844. Downloads are read and checked. Browser exceptions and console errors cause failure. Hardware receipt printing is not exercised; the print button's invocation is verified.
- Production safety: build with demo disabled and no project configuration; verify protected routes fail closed and no demo login exists.
